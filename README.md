# Engineering Interview Preparation — Hardware, Embedded & Software

This repository is a collection of technical interview preparation and engineering reference documents covering hardware design, embedded systems, electronics, programming, and engineering practices.

The documents are primarily organized in a **French / English bilingual format** and are designed for:

- Hardware Engineers
- Electronics Engineers
- Embedded Systems Engineers
- Firmware Engineers
- Power Electronics Engineers
- Test and Validation Engineers
- Technical Leads
- Engineering students and professionals preparing for technical interviews

The objective is not only to provide interview questions and answers, but also to build a practical technical reference covering concepts, design decisions, troubleshooting, calculations, and real engineering situations.
